# Gabriel Alfarth Portfolio

Portfolio pessoal de Gabriel Alfarth, com projetos, skills, curriculo em PT-BR/EN e suporte a troca de idioma.

## Deploy no Netlify

Este projeto e estatico. No Netlify, use:

- Build command: vazio
- Publish directory: `.`

O arquivo `netlify.toml` ja deixa essa configuracao pronta.
