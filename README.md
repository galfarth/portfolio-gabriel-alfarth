## O projeto

Este repositorio publica meu portfolio pessoal, com apresentacao profissional, projetos reais, curriculos em PT-BR e EN, alternancia de idioma e formulario de contato.

O site foi pensado para funcionar como uma vitrine direta: quem entra consegue ver rapidamente o que eu construo, quais tecnologias uso e onde pode falar comigo.

## Destaques

- Interface responsiva para desktop e mobile.
- Alternancia de idioma entre portugues e ingles.
- Cards de projetos com filtros por categoria.
- Modal interativo com galeria, tecnologias, recursos e links.
- Curriculos para download em PT-BR e EN.
- Deploy estatico via GitHub Pages e suporte a Netlify.
